Windows x86_64 portable build, macOS Intel and Apple Silicon app bundles, and Linux x86_64 portable archive
Git tag: `4.0.0-beta.4`

**Full Changelog**: https://github.com/dsojevic/juxtopposed-vlc/compare/beta-3...4.0.0-beta.4

This beta adapts [Juxtopposed](https://www.juxtopposed.com/)'s [VLC design](https://www.figma.com/community/file/1691465999134370980/vlc-redesign) for the native player. Work on the interface and settings workflow continues.

**Changes since `beta-3`:**
- Customize the player controls with drag and drop, save named layout presets, and remember full and compact library layouts independently.
- Add transparency and blur controls for floating player panels, menus, seek previews and settings, with improved software rendering fallbacks.
- Expand Global Settings and connect more controls to playback: audio effects, pitch, spatializer, visualizations, subtitle appearance, buffering, casting, hardware decoding and post-processing.
- Apply more settings while VLC is open, including startup behavior, window appearance, tray notifications, logging and developer controls.
- Change the interface language without restarting. Expand redesigned interface translations for British English, French, Spanish, German, Japanese, Simplified Chinese, Brazilian and European Portuguese, Russian, Italian and Turkish.
- Show expandable source groups in the queue and retain collapsed groups when switching panels.
- Show saved playback progress on folder video cards and sort folder videos by watch state without importing them first.
- Add the hosted file browser, improve native media dialogs, and extend the redesign styling to more dialogs and tooltips.
- Improve the Messages window, preserve selection and scrolling while logs arrive, and limit retained log history.
- Fix fullscreen controls, Windows titlebar hit testing, cached graphics startup, resize behavior, cursor restoration, proxy handling and single-instance startup behavior.
- Improve visualization resizing, stereo testing, subtitle rendering, streaming defaults and video color handling. Include upstream fixes.
- Check this fork’s GitHub releases daily, offer only newer compatible builds, and open the matching release page for downloads. Adopt `4.0.0-beta.N` version tags.
- Add release packaging for Linux and for both Mac architectures, using the redesigned Qt interface.

**Use:**
- Close earlier VLC windows before starting this build. Keep each download's complete contents together.
- Windows 10 (1809 or later) / Windows 11, x64: extract `vlc-juxtopposed-4.0.0-beta.4-win64.zip`, then open `vlc-win64/vlc.exe`. The empty `portable` folder stores settings beside the app. To reuse portable settings, copy your previous `portable` folder while VLC is closed.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel. Extract the ZIP and move `VLC Juxtopposed.app` into a folder of your choice. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
- Linux: extract `vlc-juxtopposed-4.0.0-beta.4-linux-x86_64.tar.gz`, then run `AppDir/AppRun`. Keep the complete `AppDir` folder together. The build targets glibc 2.35 or later (Ubuntu 22.04 or equivalent) and does not require FUSE.
- Verify downloads against `SHA256SUMS.txt` if desired. Build metadata identifies the exact source commit for each asset.

**Current limits:**
- The redesign is in progress. These are experimental builds; platform coverage does not mean every playback path has been tested.
- Windows executables have no trusted publisher signature. Mac apps are ad-hoc signed for local execution, without a Developer ID signature or Apple notarization. Operating systems may warn or block the first launch.
- Mac downloads are separate native builds; choose the correct architecture. The build metadata records the required macOS version from the bundled binaries.
- Linux still uses the host's graphics drivers and desktop/audio services; behavior can vary between distributions.
- HDR and maximum resolution settings apply to the next video. Some advanced flows still use the existing VLC interface.
- Previews for large videos or network files can take time, and decoding can still fail.
- The media library database must be on a local drive; media folders may be on a network share.
- Subtitle search does not yet parse every episode title or year. Saved folder rules support local tracks for future episodes; future online searches are not automatic.
