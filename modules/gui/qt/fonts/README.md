# Inter interface font

These unmodified fonts come from the official Inter 4.1 release:
https://github.com/rsms/inter/releases/tag/v4.1

Inter is designed by Rasmus Andersson and contributors. The included
LICENSE.txt contains the SIL Open Font License 1.1 and copyright notice.
VLC embeds the upright and italic variable fonts in the Qt interface resources.
The application loads them before creating its interface, so an operating-system
font installation is not required. Other system fonts remain available for
characters that Inter does not contain.
